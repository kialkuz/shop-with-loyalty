Сервис накопления баллов лояльности за заказы пользователя.

Необходимо экспортировать переменные, либо использовать флаги при запуске.
Если использованы переменные и флаги, то у переменных приоритет выше.
RUN_ADDRESS, флаг a - url сервиса лояльности
DATABASE_URI, флаг d - url бд
ACCRUAL_SYSTEM_ADDRESS, флаг r - url системы начисления баллов
SECRET_KEY, флаг k - ключ для шифрования JWT

Документация Openapi работает по ссылке http://localhost:8080/swagger/
